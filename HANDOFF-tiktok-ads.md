- **Fix (site `1b4a9f9`, pushed → production):**
  1. One shared limiter for every call to business-api.tiktok.com — `tiktokFetch()` in `src/lib/analytics/tiktok.ts`, kept on `globalThis` so analytics, ads (`src/lib/ads/tiktok.ts`), Money (`src/lib/money/adSpend.ts`, now via `tiktokCall`) and publishing (`src/lib/publish/tiktokBiz.ts`) all queue on it. 5 starts a second and 3 in flight (under the 6 asked for, because Vercel may run two routes in separate function instances that can't share a limiter; the retry covers the overlap).
  2. Code 40100 retries after 0.5 s, 1 s, 2 s, then the error is shown as before.
  3. `tiktokCampaigns()` fetches the campaign-level report first; an account with nothing in the window stops at that one request (no daily or ad-level rows, no campaign/get or ad/get). A 40001 scope refusal is remembered for 10 minutes per endpoint + account, so the missing scope costs one request per load instead of one per page. `ad/review_info/get` (404 on v1.3) is off unless `TIKTOK_REVIEW_INFO=1`.
