### Result, part 4 (Claude Code, 2026-10-28) — live status, honest reuse_angle, Not delivering
- **Site `cc0b903`** → production. **studio-ios `5bf7cc5`** (built for the iPhone 17 Pro simulator with Xcode 27.1; no new Swift files; **run ./build-to-phone.sh**). tsc + lint clean (3 pre-existing warnings).
- 1) **Live status.** Root cause of "Pause" on a paused campaign: `campaigns.ts` wrote `c.status_detail || c.operation_status ? word : undefined` — `||` binds tighter than `?:`, so every TikTok row with a secondary status carried the raw `CAMPAIGN_STATUS_DISABLE` string, never `paused`, and the Pause rule fell back to "spent in the last 2 days". Fixed. `tiktokStatusWord` now lets `operation_status DISABLE` win over a stale secondary status; `AD_STATUS_DELETE` maps. New `liveStatus(row)` in `insights.ts` (running / paused / ended / scheduled / in_review / rejected / no_funds / unknown; `budget_spent` = running; a running campaign whose every ad is paused / ended counts as paused / ended). While TikTok's scope is pending, a Studio boost's `studio_promotions` row (status + start/end window) stands in for the platform status, with its own tooltip note. Meta campaigns now carry `created_time` / `start_time`.
  - Pause: only when `liveStatus` is running (or unknown — then the detail says "skip this if you already paused it in Ads Manager"). Already paused + Needs work → a `pause` action with `done: { label: 'Paused ✓' }`, no button, score 10 (drops off the top-5 when there's real work), and it no longer takes the one-Pause-per-app slot. Ended / rejected / spent-then-stopped → no actions, as before; a campaign that never spent is no longer treated as "over".
- 2) **reuse_angle** says "It converts: N installs at $x each." only when installs ≥ `MIN_INSTALLS` (20); otherwise "It gets cheap clicks (CTR x%, CPC $y) — N installs so far, under the 20 needed…" / "— installs aren't visible yet, so it isn't proven to convert."
- 3) **Not delivering** (`STALLED = { min_age_hours: 24, max_impressions: 100 }`): liveStatus running, live ≥ 24 h since the later of created / started (TikTok `create_time` UTC, Meta `created_time` / `start_time`, Studio boost `start_at`), < 100 impressions in the range → verdict `not_delivering` (amber pill, before Too early) with action `widen_audience`: "Open ad group" (TikTok, `adGroupManagerUrl` = Ads Manager ad-group level searched by campaign id, plus the scope note) / "Open ad set" (Meta, the campaign's ad sets view). Jinglewire's detail keeps it parents-only. Age unknown (TikTok without scope and no Studio record) → stays Too early, by design: no guessing. The narrative prompt knows the verdict and that the fix is audience / bid / budget floor, not creative.
